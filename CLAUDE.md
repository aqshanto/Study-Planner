# Project rules

- Stack: Python 3, Flask, Flask-SQLAlchemy (SQLite), Flask-Login, Jinja2, Bootstrap 5 via CDN.
- This is a learning project. Keep code simple and beginner-readable, with short comments.
- Do not add new libraries without asking me.
- Only modify the files I name in my request.
- Hash passwords with werkzeug.security. Secrets go in .env via python-dotenv.
- After each change, explain in 5 short bullet points how it works.
